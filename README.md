# Accessibilité

## Guides et outils d'aide à la vérification de l'accessibilité numérique du BPNM

Un ensemble de ressources pratiques destinées à accompagner les équipes dans le contrôle et l'amélioration de l'accessibilité de leurs interfaces numériques. Il comprend des guides méthodologiques présentant les critères RGAA applicables, des grilles de vérification simplifiées pour les tests de premier niveau, ainsi que des outils facilitant le repérage des non-conformités les plus courantes
